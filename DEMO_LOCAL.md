# Ejecutar Agenda Caucana en otro computador

Para descargar y probar la copia local actual, sigue la guía [GUIA_ENTREGA_PRUEBAS.md](./GUIA_ENTREGA_PRUEBAS.md). Incluye arquitectura, requisitos, configuración de PostgreSQL, creación de administrador, comandos para iniciar frontend/backend, pruebas recomendadas y el prompt de contexto.

Esta entrega no incluye el `.env`, la base PostgreSQL del computador de desarrollo, archivos locales de `uploads`, respaldos ni dependencias instaladas. Cada computador debe crear sus propios secretos y su propia base de pruebas.
